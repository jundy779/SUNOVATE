# SUNOVATE v0.1.0 — Fondasi

**Tanggal:** 1–2 Oktober 2026
**Status:** Versi pengembangan, belum siap produksi. Seluruh data adalah data contoh (`SIMULATED_DATA`).
**Commit:** `357df94` (feat: initial SUNOVATE foundation scaffold)

## Isi rilis

- Kerangka aplikasi web (Next.js) dan API (FastAPI) dalam satu repository: halaman masuk pengembangan, ringkasan, basis pengetahuan, pencarian, monitoring kerja, tanya jawab dengan asisten AI, dan administrasi.
- Pengamanan dasar: setiap data diperiksa terhadap izin, tim, dan tingkat kerahasiaan; audit tercatat dan tidak dapat diubah; persetujuan tidak boleh diputuskan oleh pengaju sendiri.
- Rancangan basis data PostgreSQL 30 tabel dengan migrasi dan data contoh.
- Dokumentasi proyek lengkap di `docs/`, termasuk pertanyaan terbuka, keputusan arsitektur, dan register risiko.

## Batas

- Belum ada model AI, data asli, server kantor, atau integrasi dengan sistem lain.
- Rincian teknis dan hasil validasi: lihat `CHANGELOG.md` bagian 0.1.0.
