# Governance

**Status:** NEEDS MENTOR VALIDATION  
**Last Updated:** 2026-10-01

Governance menjaga keputusan dapat ditelusuri dan mencegah asumsi berubah menjadi fakta.

## Mechanisms

- **CONFIRMED:** setiap klaim penting memakai label CONFIRMED, PROPOSED, OPEN QUESTION, atau OUT OF SCOPE.
- **PROPOSED:** keputusan teknis dan produk dicatat sebelum implementasi yang bergantung padanya.
- **PROPOSED:** risiko ditinjau pada setiap checkpoint mentor.
- **CONFIRMED:** detail proses SUN, angka, jabatan, dan alur approval tidak boleh dikarang.
- **CONFIRMED:** mock integration harus selalu dibedakan dari koneksi produksi.

## Review cadence

- **PROPOSED:** review keputusan, risiko, dan pertanyaan terbuka pada checkpoint yang disepakati.
- **PROPOSED:** perubahan status membutuhkan bukti atau persetujuan stakeholder berwenang.
- **OPEN QUESTION:** frekuensi dan peserta forum review.
