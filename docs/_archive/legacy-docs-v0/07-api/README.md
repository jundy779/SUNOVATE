# API Contract

**Status:** PROPOSED  
**Last Updated:** 2026-10-01

## Contract

- **CONFIRMED:** FastAPI is the sole business API boundary; Hermes and the web client do not access PostgreSQL directly.
- **PROPOSED:** versioned REST base path `/api/v1`, OpenAPI generated by FastAPI, JSON request and response bodies.
- **PROPOSED:** Pydantic v2 validates trust-boundary input and shapes output; SQLAlchemy 2 handles persistence.
- **PROPOSED:** list endpoints use server pagination, filtering, sorting, and explicit maximum page sizes.
- **PROPOSED:** mutations use optimistic version checks where concurrent edits can lose data.
- **PROPOSED:** normal business records are archived, not hard-deleted.

## Initial groups

`/auth`, `/users`, `/roles`, `/teams`, `/dashboard`, `/work-outputs`, `/tasks`, `/meetings`, `/inspections`, `/knowledge`, `/documents`, `/sun-business`, `/reports`, `/integrations`, `/audit`, and `/ai`.

These groups describe boundaries, not completed endpoints. SUN business mutations and exact fields remain **OPEN QUESTION** until process validation.

## Error model

```json
{
  "code": "RESOURCE_NOT_FOUND",
  "message": "Resource was not found",
  "details": null,
  "request_id": "generated-request-id"
}
```

Use `400/422` for invalid input, `401` unauthenticated, `403` forbidden, `404` absent, `409` version conflict, and `500` unexpected failure. Responses must not expose stack traces, secrets, or restricted content.

## Hermes boundary

- **CONFIRMED:** Hermes receives user authorization context and calls allowlisted endpoints.
- **CONFIRMED:** sensitive writes require approval before execution.
- **PROPOSED:** each AI response returns source identifiers suitable for user-visible citations.
- **OUT OF SCOPE:** unrestricted natural-language SQL or database credentials for Hermes.
